## Required fields before publishing a specific result

| Evidence field | Minimum public-safe carrier |
| --- | --- |

## Release sequence

1. Locate original pilot evidence in the controlling source estate; record its unchanged fingerprint and provenance.
2. Identify customer/operator-owned material and any contractual or NDA restriction.
3. Produce a narrowly redacted, separately labeled **public extract** retaining enough to test the precise public claim. A synthetic illustration is never described as an original pilot event.
4. Preserve the original run packet privately and link the public extract to an immutable evidence ID. A hash without released observations is not a substitute for the observations.
5. Mark exactly **CORPUS RECORDED**, **PILOT OBSERVED**, or **INDEPENDENTLY REPRODUCED** as supported by the released carrier, and state what remained confidential.
