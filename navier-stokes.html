The generated kernel is the formula

The URK generator produces the domain mathematical kernel/formula. Input data are evaluated through that generated formula; its results and witnesses are then tested against the exact mathematical proposition.

URK generator→ Generated kernel = formula→ Input data→ Outputs & witnesses→ Proof verification

Exact available demonstration: the public-safe Continuation 77 Fourier edge-rate specialization takes six mode inputs and reproduces 30 ordered interactions and a zero finite-snapshot kinetic/heat balance residual. Its replay exactly matches the original archived example; the new public verifier passed 11/11 checks. This is distinct from both the protected original URK generator and the independently reconstructed 122/250-mode midpoint comparison.

Scope: no public record in this bundle yet authenticates an original native generated Navier–Stokes kernel as an unrestricted three-dimensional global-regularity theorem. The original classical proof source, its hypotheses, and the separate historical 17/17 finite-mode replay remain preserved.

Reproducibility and bounded scope

The public bundle includes the original Part II classical LaTeX-source excerpt, the independent periodic Fourier–Galerkin midpoint replay, its six-mode seed, saved 122- and 250-mode comparator records, and verification report. The locally rerun comparator passed 17/17 checks in this preparation. This is numerical finite-mode evidence; it does not by itself demonstrate unrestricted global regularity.

  1. Inspect the replay source on GitHub and requirements.
  2. Download the public-source ZIP and unzip it.
  3. From the extracted directory run python -m pip install -r 05_REPRODUCIBILITY/requirements-replay.txt.
  4. Run python 05_REPRODUCIBILITY/independent_midpoint_replay.py --output independent_replay_result.json.
  5. Inspect the new JSON output alongside the saved comparison result.
