# V.A. ZERO-X — public interactive consequence examiner

This is a static, browser-local site intended for GitHub Pages. No server, account, API, proprietary native kernel or Python installation is required for the on-page demo.

**Start:** Visit `/va-proof-estate/zero-x/` (or open the separate offline ZIP), describe a hypothetical consequential workflow, run the sample, edit authority/capacity/water/route conditions, inspect before/after *mock* state and download your report. You can import responses from your own offline system as JSON. No visitor workflow inputs are transmitted by this page (ordinary web hosting traffic remains subject to GitHub Pages' infrastructure).

**Evidence limit:** The browser's embedded decision procedure is an independently authored, conventional synthetic reference, **not V.A.'s proprietary True Zero / corrected NEW K / URK implementation**. Its after-state is a simulated state, not a separately observed hardware/customer effect. Passing the browser case demonstrates only agreement with the public synthetic scenario, not native V.A. or independent physical proof. A signed JSON report is not created by this page.

**Challenge:** 6 synthetic facilities, 8 modeled consequence routes, authority revocation, contradictory capacity, local water veto, stale evidence, replay/duplication, and cumulative workload conservation. The 10–100-year stress figures on-page describe *input corpus sizes only*, not completed native outcomes. [Native requirements](NATIVE_RESULT_HANDOFF.md) and [formal obligations](FORMAL_EXAMINATION_OBLIGATIONS.md) are attached.

**Privacy:** Import only non-sensitive bounded test JSON, not protected code, identity documents, credentials, or customer data. Local file uploads in this interface are processed in your browser; it does not call any external API to process the contents.

**Source provenance and independence:** The challenge was inspired by publicly published discussions of AI data-center resource governance, including the independent ZERO research of Maria Kollia. It is **not CEOS/ZERO source**, not a run of that technology, not a claim of collaboration, and not an endorsement. The unaltered official V.A. PNG is retained in the original offline ZIP. On GitHub Pages, 12 static base64 source parts reconstruct its exact original bytes in the visitor browser; the result is displayed only after its original SHA-256 verifies. No substitute logo is used. Serving the site over HTTP(S) is required for this hosted representation; opening the page directly with `file://` can block asset loading.

**Deploy:** Host all files in this directory under `/va-proof-estate/zero-x/` on the existing GitHub Pages site. Do not publish protected V.A. kernel, private partner records, or unsafe physical/KCD content.
