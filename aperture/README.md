# V.A. Consequence Aperture — Stage A

**Release status:** public-safe examiner workbench + local byte preflight. **No live native V.A. endpoint, no instrumented original, no independently reproduced native proof attached.** Existing historical pilots and original sources retain their separate provenance. No private True Zero, corrected NEW K, URK, KCD, or substrate construction is published.

This is not another predetermined consequence simulation. The workbench does not generate a predicted consequence or assign PASS. An examiner supplies original data and the preflight checks that the **exact submitted bytes** match the manifest, and that the proposed four control roles are complete. This cannot authenticate the effect itself, sensor calibration, signer identity, chronology, independent status, safe operation or native execution.

## Public workbench

[Open Consequence Aperture](../consequence-aperture.html)

1. Record the exact SHA-256 of a privately held frozen artifact; establish an independent source/time anchor **before** challenge issuance. A downloaded draft is not an issued challenge or freeze.
2. A separately identified examiner issues an unforeseen bounded condition **after** the freeze. Existing [freeze-first public examiner protocol](../examiner/INDEPENDENT-CHALLENGE.md) is for **synthetic** source-pinned examination and may be used as an administrative reference, not an implied native effect.
3. Record the declared protected effect, observation scope, and inventory of alternate routes. Preserve separate original sensor readings and receipts for **POSITIVE**, **NEGATIVE**, **CHANGED**, and **REPLAY**.
4. Make a UTF-8 JSON packet under `VA-APERTURE-1`. Each referenced original is a flat filename and exact original SHA-256. Originals can be retained privately with the examiner; do not publish health, financial, proprietary or personally identifiable data without clearance.
5. Check in the browser locally or reproduce offline.

```sh
python aperture/verify_packet.py packet.json --originals /path/to/originals
python aperture/test_verify_packet.py
```

A successful preflight returns `ok: true` and **standing: DECLARED_ONLY**. It means exact supplied files match declared hashes and structural controls are present. An externally attested witness, physical effect, custody, and independent reproduction require separate independent qualification. A genuine falsification (e.g., the measured positive effect was **false**) is valid input and must **not** be masked as PASS.

## Packet shape (no results are invented)

```json
{
  "schema": "VA-APERTURE-1",
  "packet_id": "locally-identified-case",
  "standing": "DECLARED_ONLY",
  "freeze": {
    "artifact_id": "frozen-build-id",
    "owner_id": "custodian-id",
    "artifact_sha256": "<64 lowercase hex characters>",
    "frozen_at": "2026-11-03T10:00:00Z",
    "anchor": "https://independent.example/freeze-record"
  },
  "challenge": {
    "id": "examiner-challenge-id",
    "examiner_id": "distinct-issuer-id",
    "issued_at": "2026-11-03T11:00:00Z",
    "condition_summary": "Previously undisclosed condition"
  },
  "boundary": {
    "protected_effect": "Precisely bounded effect or prohibited effect",
    "observation_scope": "Sensor and target measurement scope",
    "alternate_routes": ["primary", "fallback"]
  },
  "controls": [
    {"kind":"POSITIVE","condition_id":"baseline","measured_effect":true,"measurement_file":"pos-sensor.txt","receipt_file":"pos-receipt.txt"},
    {"kind":"NEGATIVE","condition_id":"revoked","measured_effect":false,"measurement_file":"neg-sensor.txt","receipt_file":"neg-receipt.txt"},
    {"kind":"CHANGED","condition_id":"changed","measured_effect":false,"measurement_file":"change-sensor.txt","receipt_file":"change-receipt.txt"},
    {"kind":"REPLAY","condition_id":"baseline","measured_effect":true,"measurement_file":"replay-sensor.txt","receipt_file":"replay-receipt.txt"}
  ],
  "witness": {"id":"witness-id","statement_file":"witness.txt"},
  "originals": [
    {"file":"pos-sensor.txt","sha256":"<actual SHA-256 of pos-sensor.txt>"}
  ]
}
```

The example above is **incomplete and illustrative only**; every measurement, receipt, and witness statement file must appear exactly once in `originals` and physically exist in the supplied `--originals` directory. Recorded `measured_effect` booleans are claims, not values generated by the verifier. Their truth is **not** verified by their presence.

## Advancement route

- **Stage A — implemented:** public examiner request and original-byte preflight; automated negative controls and standalone public documentation.
- **Stage B — not connected:** an authorized, constrained native V.A. execution carrier, separate calibrated actual-effect instrument, private kernel custody and safety review.
- **Stage C — not established by Stage A:** separate examiner identity/independence confirmation, original readings, separately retained witnessed replay, independent negative controls and rights-cleared release. Do not automatically promote from Stage A.

**The face may vary. The floor must not.** Protected construction stays private. Examination of function does not imply disclosure of how the function is built.
