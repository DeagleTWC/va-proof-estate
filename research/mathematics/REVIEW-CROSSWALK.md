## What an examiner can verify

1. **Claim:** State the precise theorem, domain, quantifiers and assumptions. Preserve the author-supplied original.
2. **Carrier:** Bind the exact file edition, SHA-256, manuscript equation/theorem reference, and release manifest.
3. **Computation:** Run only the public-safe verifier or archived comparison corresponding to that claim. A passed finite test is bounded evidence.
4. **Review:** Where independently reportable, retain the separate examiner's identity/affiliation, independence/conflicts, date, examined file hash, reproducibility actions, objections and final bounded disposition. **Do not infer these fields if no public carrier supplies them.**
5. **Scope:** Preserve every unresolved antecedent and falsifier. Do not treat a publication navigation correction as proof completion.

An external mathematics reviewer may reference the [public mathematical research index](../../mathematics.html), [general examiner route](../../reviewer-route.html) and [responsible examination notice](../../SECURITY.md). A qualified independent mathematical peer assessment and independent measured consequence examination are different disciplines. The latter is separately defined in [V.A. independent observation qualification](../../proofs/INDEPENDENT-OBSERVATION-QUALIFICATION.md).
