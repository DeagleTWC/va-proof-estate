## 1. Universal conjecture in exact lattice form

Let X be **any** smooth complex projective variety, let n = dim_C X, and let 0 ≤ p ≤ n. Define

- H_Z = H^(2p)(X,Z) / torsion;
- B_p(X) = { b in H_Z : b is of Hodge type (p,p) };
- A_p(X) = subgroup of B_p(X) generated by the cohomology classes cl(Z) of **actual codimension-p algebraic cycles Z on X**;
- Sat_B(A) = { b in B : some positive integer m has m*b in A }.

Then the following is an **exact equivalence**:

    Rational Hodge Conjecture for (X,p)
      <=> A_p(X) tensor Q = B_p(X) tensor Q
      <=> Sat_(B_p(X))(A_p(X)) = B_p(X)
      <=> rank_Z(A_p(X)) = rank_Z(B_p(X)).

The **unrestricted conjecture** is the universal assertion that these equivalent conditions hold for every smooth complex projective X and every p. This assertion is not established merely by writing the equivalence.

### Proof of the equivalence (not a proof of the conjecture)

If every rational (p,p) class is a rational linear combination of genuine algebraic-cycle classes, multiply an integral Hodge class by a common positive denominator to obtain an element of A_p. Thus its saturation is all of B_p.

Conversely, any rational (p,p) class has a positive integral multiple in B_p. Full saturation supplies a further positive multiple belonging to A_p, proving the class lies in the rational span of actual algebraic cycles.

Because A_p is a subgroup of the finite-rank free abelian group B_p, saturation equals B_p exactly when the two groups have the same rank. QED.
