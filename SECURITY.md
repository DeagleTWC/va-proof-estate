# Responsible technical examination

The public Proof Estate welcomes reproducible, bounded review, including tests that falsify a stated claim. Conduct only authorized tests against your own local copy of the publicly released synthetic fixture or a separately permissioned environment.

- Never probe production customers, hospital systems, privileged accounts, external providers, or private endpoints without their express authorization.
- Do not publish credentials, access tokens, customer-paid pilot records, protected mathematics, confidential build instructions, or identifiable personal records.
- Preserve exact artifact hashes, an unaltered observation record, and the examined scope. Do not use a screenshot or a refusal message as a substitute for measured non-effect.
- If an issue might reveal a usable weakness, refrain from posting exploit details to the public GitHub issues list. Use a private, permissioned reporting arrangement with the system custodian.
- Clearly distinguish a public-specification defect from a verified native-runtime defect; the same examiner rule applies to both.

**Public function is examinable. Protected construction remains under custody.**
