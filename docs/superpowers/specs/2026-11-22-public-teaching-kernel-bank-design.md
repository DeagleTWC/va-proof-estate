# Natural Order Teacher — Public Teaching Kernel Bank

## Intent

Help visitors learn from V.A.'s public source estate without requiring an LLM, a private foundation, or a pre-existing technical vocabulary. Add a durable bank of executable **teaching exercises** that can be expanded through versioned review cycles as visitors voluntarily report missing examples.

## Starting material and boundary

Terry supplied `ultramegakernel.txt`, then explicitly corrected the direction: the mega file is **idea material**, and the work must start from an actual generator. We examined the historic `urk_kernel_generator_v1.zip`, July's `UNIVERSAL RESOLVING KERNEL GENERATOR v0.1`, and Frankie's more recent private Cycle 045 / 049 native candidate-formation interfaces. The Cycle 049 generator passed six native regression tests and an isolated generated-candidate/replay test; the candidate remained non-executable (`activated=false`, `external_effect=false`). No private generator or protected mathematics is copied into the public estate.

The public bank is a **reviewed educational derivative of the generator's generation/check/classification/replay pattern**, not a native mathematical kernel generated for execution. The historic K equations are not allowed to stand in for corrected NEW K. No source in this work claims proof of universal physical or mathematical equivalence.

## Selected approach

1. **Chosen:** a tested, versioned bank of small, independent public teaching exercises. Each begins with a scenario and changed condition, asks the visitor to distinguish a useful witness from a weaker explanation, gives specific feedback, and links a source. A visitor can continue to the next exercise without inventing a question.
2. Rejected for now: an untested automatic generative teacher. It cannot be run from GitHub Pages without a service and would change the current no-transmission promise.
3. Rejected: merely adding prose pages. They cannot test a visitor's understanding of evidence or changed conditions.

## Behavior

- Eleven public exercises, one for each existing named public route. No private formulas, construction details, authorizations, or personal data.
- A Definition Conversion Kernel shows a short plain-language expansion at first mention of a public V.A. term and an optional deeper definition and source. This is a glossary mechanism, not an operative kernel.
- A pure `assessTeachingKernel(id, choiceId)` yields **educational feedback**, not a runtime ALLOW/DENY, mathematical proof or safety certification.
- A pure `auditTeachingKernelBank()` examines each entry's finite public scope, `reversible`/non-mutating property, required educational invariants, unique choice IDs, valid selection, single known topic and source eligibility. Fail closed on invalid/unknown entries.
- The interactive Teacher shows the matching exercise after an ordinary source lesson; a separate bank catalog permits starting anywhere and going to the next lesson.
- Ordinary source lookup, protected-review routing, Frankie-disabled state and public source links keep working.
- Accessible controls, DOM-safe text insertion, reduced-motion support and responsive styling.
- No telemetry, cookies, storage or silent submission. Offer a separate, explicitly voluntary email link to suggest a missing example, not an automatic question upload. The page continues truthfully to say that it does not send or store entered learning text.

## Proof and release requirements

Red/green tests for admission, every subject route, wrong answers, missing/unavailable data, indefinite continuation, and source safety. Exercise rendering is manually checked in a browser. Public audit pins the approved directory, forbids unintended network calls and private material, and preserves offline CSP `connect-src 'none'`. Before publishing, full regression and release audit pass. Frankie remains separately versioned and inactive publicly.
