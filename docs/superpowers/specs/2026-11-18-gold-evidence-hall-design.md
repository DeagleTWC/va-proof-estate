# V.A. Gold Evidence Hall — approved design

## Intent

Build a beautiful, self-contained examination entry point inside DeagleTWC/va-proof-estate. Present five distinct boundary questions—pre-effect custody, authority revocation, scope expiry, changed conditions, and lawful continuance/replay—using existing original public V.A. source PDFs and the one existing local synthetic examiner fixture. Do not depend on Kamanaka links or disclose protected mathematical construction.

## Surface

- One new `evidence-hall.html` route, sharing `va-gold-design.css` and using the existing official V.A. SVG mark and obsidian/antique gold/ivory palette.
- One accompanying `evidence-hall.css` for responsive cards, evidence status badges, proof pathways, clear hierarchy, and reduced-motion handling.
- A five-exhibit register with exact local public carrier paths, scopes, and evidence class labels; clearly mark documentary source claims as DECLARED and the local `VA-AD-001` mock as OBSERVED within its bounded scope only.
- Link the hall from the homepage navigation and hero without disturbing existing demonstrations or public archives.

## Boundaries

- Original public PDF bytes and original historical source indexes are untouched; preserve original attributions.
- No outbound Kamanaka URLs in the new Hall. No third-party code is copied.
- No evidence promotion: no native V12 original run packet or independent reproduction is attached by this change.
- No interactive simulation pretending to be native V.A.; static illustrative pathways are clearly marked.
- Existing source records and public proof atlas remain available as-is, including historical provenance references.

## Alternatives considered

1. One integrated Hall (chosen): compact, gold, coherent, and navigable from the main estate.
2. Five separate new microsites: more maintenance and unnecessary duplication.
3. Mirror whole source repos: would lose source-rights boundaries, add external dependencies, and reproduce non-native stacks.

## Acceptance

- All five exhibits render and use local evidence links only.
- At least one real bounded fixture result is correctly described, with no suggestion of actual native effect.
- Claims, receipts, and PDF files are not altered; page reflects current public proof ceilings.
- Navigation is keyboard-accessible, responsive, and preserves the V.A. visual identity.
