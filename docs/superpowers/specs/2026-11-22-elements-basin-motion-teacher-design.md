# Elements Basin Motion — Public Teacher Design

## Intent

Carry Terry Snyder's clarified Natural Order terminology into the public Teacher: the Elements Basin is identified *in the Natural Order account* with what is conventionally called dark matter; the Basin is in motion, not a stationary medium through which Earth is simply pushed. The KCD design inversion holds a protected interior while surrounding field relations are examined. Natural Order “water” is an element of that account, not the chemical molecule H2O. Horizon inaccessibility is not proof of destruction.

## Approach

Chosen: update the existing Elements Basin lesson and definition, plus a small, explicit source-bound answer route for visitor questions about this identification and motion. An additional cosmology kernel would blur the eleven-subject boundary; changing only a static paragraph would leave direct visitor questions routed by weak keywords. No new kernel or external service is created.

## Guardrails

- Attribute physical interpretations to the Natural Order account; a proposed correspondence is not independently established cosmology.
- Gravity-as-wave-array, conservation through a horizon and the Basin/dark-matter identity are not promoted to observed physical results.
- KCD is a formal, bounded protected-interior/exterior-field examination program. Its public physical proof series has no attached completed independently measured new physical run.
- Do not copy or publish the uploaded controlled KCD source archives, mechanics, operators, code or configurations. Only link already-public KCD and foundation pages.
- Preserve patient clarification for ambiguous uses of “dark matter”, “water”, “gravity”, or “horizon”; do not hijack unrelated astronomy or chemistry questions.
- Full-text protected-access checks retain priority; exactly eleven subject kernels remain.

## Acceptance

Direct, explicit Natural Order questions receive a patient attributed explanation, local public source links and a clear evidence ceiling. Generic physical questions remain open for clarification. Existing tests, release audit, disabled Frankie boundary and versioned browser imports pass.
