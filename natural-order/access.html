HOW THE PRIVATE HANDOFF WORKS

01 / REQUEST

Ask for the appropriate NDA.

Introduce yourself and the public evidence or engineering question you want to examine. Terry provides the current agreement suitable for the specific review; an existing bilateral NDA is not a reusable public form.

02 / SIGN & RETURN

Read, sign, and email it.

Review the supplied NDA, sign only if you agree to its terms, and email the signed copy to the private return address Terry provides directly. Do not post signed agreements or personal information to the public repository.

03 / PERSONAL TOUR

Set the examination scope.

After Terry receives and reviews the signed agreement, he can arrange a personal walkthrough and determine which protected material, if any, is authorized for that specific examination.
