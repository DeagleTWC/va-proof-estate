No converted systems or downstream brands are included. No protected construction, live V.A. runtime, original historical run receipts, or independently reproduced physical results are disclosed by this website.

**Evidence rule:** Every claim terminates in a carrier. Function must be open to examination. Construction need not be open to reconstruction.
